Getting Started

Introduction

V5 is a spatial intelligence platform that fuses satellite imagery, geolocation signals, and AI-driven analysis into a single, unified API and interface.

Early Access: V5 is currently in closed beta. API access requires an approved account. Request access →

What is V5?

V5 provides three core capabilities:

Geospatial Analysis Sub-meter satellite imagery, terrain mapping, and zone monitoring.
AI Detection Neural network models for object detection, anomaly flagging, and pattern recognition.
Real-Time Intelligence Live monitoring zones, webhook alerting, and stream API feeds.

How it works

V5 exposes a REST API and a WebSocket stream. You authenticate with a bearer token, submit queries with geographic coordinates or bounding boxes, and receive structured JSON responses containing imagery metadata, detections, and confidence scores.

Quick Start

Get up and running with the V5 API in under five minutes.

1. Get your API key

After your account is approved, navigate to Dashboard → Settings → API Keys and generate a new key. Keep this secret — it grants full access to your account.

2. Make your first request

Use your API key as a bearer token in the Authorization header:

bash 
# Geolocate a coordinate pair
curl -X GET "https://api.v5intel.io/v1/geolocate" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "lat": 48.8566,
    "lng": 2.3522,
    "radius_km": 5
  }'

3. Parse the response

A successful response returns a JSON object:

json 
{
  "status": "ok",
  "query_id": "qry_01HX4M9Z...",
  "result": {
    "lat": 48.8566,
    "lng": 2.3522,
    "confidence": 0.97,
    "imagery_available": true,
    "last_updated": "2026-03-05T18:42:00Z",
    "detections": [
      { "type": "vehicle", "count": 14, "confidence": 0.91 },
      { "type": "structure", "count": 3, "confidence": 0.88 }
    ]
  }
}

Authentication

All V5 API requests must be authenticated using a bearer token.

API Keys

Pass your API key in the Authorization header on every request. Keys are scoped per account and respect your plan's rate limits.

http 
Authorization: Bearer v5_sk_live_xxxxxxxxxxxxxxxxxxxxxxxx
Keep keys secret. Never expose API keys in client-side code, public repos, or logs. Rotate compromised keys immediately in the dashboard.

Key Types

Prefix Type Use case
v5_sk_live_ Secret (live) Production server-side requests
v5_sk_test_ Secret (test) Development — uses sandboxed data

Geolocation Engine

V5's geolocation engine triangulates positions using multi-source signal correlation.

Data sources

The engine fuses signals from multiple independent layers:

  • Satellite imagery — visual confirmation via optical and SAR bands
  • RF signal correlation — cross-references detected radio frequency emissions
  • Open-source databases — cross-referenced against publicly available spatial datasets
  • Historical delta analysis — compares against prior imagery to detect change

Confidence scoring

Every geolocation result includes a confidence float between 0.0 and 1.0. Scores above 0.85 are considered high-confidence.

Zone Monitoring

Define geographic zones and receive automatic alerts when changes are detected.

Creating a zone

Zones are defined by a GeoJSON polygon or a center point with radius:

json 
{
  "name": "Alpha Zone",
  "geometry": {
    "type": "circle",
    "center": { "lat": 48.8566, "lng": 2.3522 },
    "radius_km": 10
  },
  "alert_on": ["vehicle_movement", "structure_change"],
  "webhook_url": "https://your-server.io/hooks/v5"
}

AI Detection

Neural network models trained on millions of labeled geospatial data points.

Detectable objects

  • Vehicles (cars, trucks, aircraft, vessels)
  • Structures (buildings, installations, encampments)
  • Personnel clusters (crowd density estimation)
  • Environmental changes (deforestation, flooding, excavation)
  • Infrastructure (roads, bridges, power lines)
Custom model fine-tuning is available on the Command plan. View plans →
